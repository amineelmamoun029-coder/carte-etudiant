Carte Étudiant - React Native

Description:

Ce projet est une application mobile développée avec React Native et Expo dans le cadre d'un TP.

L'application affiche :

Le logo de l'EMSI
Le nom de l'étudiant
Le prénom de l'étudiant
L'année universitaire

Technologies utilisées:

React Native
Expo
JavaScript
Git
GitHub
VS Code

Fonctionnalités:

Affichage du logo EMSI
Affichage des informations de l'étudiant
Interface simple et moderne

Exécution du projet:

npm install
npm start
